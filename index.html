clipou

O clipou é uma ferramenta interna do canal CLIPOU NO GTA. Ela envia para o YouTube os vídeos curtos produzidos pelo próprio canal, usando a API oficial do YouTube.

O aplicativo é usado apenas pela equipe do canal, na conta do próprio canal. Ele não é oferecido ao público e não tem cadastro de usuários.

O que o app faz

  • Envia vídeos para o canal CLIPOU NO GTA no YouTube.
  • Consulta o nome e o identificador do canal para confirmar que o envio vai para a conta certa.
